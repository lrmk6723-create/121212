# Expense Tracker (Трекер расходов)

**Автор:** Мищенко Андрей Романович

## Описание программы

Expense Tracker — это GUI-приложение для отслеживания личных расходов. Оно позволяет добавлять расходы, фильтровать их по категории и дате, считать сумму расходов за выбранный период, а также сохранять и загружать данные в формате JSON.

## Как использовать

1. Убедитесь, что установлен Python 3.6+.
2. Запустите файл `expense_tracker.py`:
   ```bash
   python expense_tracker.py
